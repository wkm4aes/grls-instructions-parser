# grls-instructions-parser

Скрипт на Python, который по номеру регистрационного удостоверения (РУ) находит
карточку препарата в [Государственном реестре лекарственных средств](https://grls.rosminzdrav.ru/)
(ГРЛС, grls.rosminzdrav.ru) и скачивает PDF-файлы инструкции по медицинскому
применению — включая все зарегистрированные редакции/изменения, а не только
последнюю.

Передаёте список номеров РУ (или готовых адресов карточек / GUID) — на выходе
папка с PDF и `manifest.json` на каждый препарат: метаданные файла, номер
изменения, год, SHA-256, прямая ссылка.

## Как это работает

Сайт ГРЛС — классическое ASP.NET WebForms-приложение, собственного открытого
API у него нет. Скрипт воспроизводит действия браузера обычными HTTP-запросами:

1. **Поиск по номеру РУ.** `GET /GRLS.aspx` → забираем `__VIEWSTATE` /
   `__EVENTVALIDATION`, затем `POST /GRLS.aspx` с полем
   `ctl00$plate$txtRegNm=<номер РУ>` (обычный постбэк формы). В ответе —
   таблица результатов, где у каждой строки `onclick="det('<guid>', <isFS>)"` —
   это и есть `routingGuid` нужной карточки.

   На странице поиска есть капча (canvas с искажённым текстом), но это
   **не серверная защита**: используется открытая JS-библиотека
   [jquery-captcha](https://github.com/honguangli/jquery-captcha), которая
   рисует код и сверяет введённый ответ тут же в браузере — ответ никуда не
   отправляется, и сервер его не проверяет. Обычный постбэк формы без браузера
   проходит и без «решения» этой капчи — это не обход защиты, а просто то, что
   проверка изначально клиентская и не формирует часть серверного контракта.

2. **Карточка препарата.** `GET /Grls_View_v2.aspx?routingGuid=<guid>` — из HTML
   достаём номер РУ, внутренний `idReg`, торговое название и (если есть)
   JSON-модель списка файлов инструкции из скрытого поля `hfInstructionModel`.

3. **Список файлов, если поле пустое.** Тот же JSON отдаёт
   `POST /GRLS_View_V2.aspx/AddInstrImg` с телом `{"regNumber", "idReg"}`
   (нужны cookie сессии, полученные на шаге 2).

4. **Скачивание файлов.** Пути в JSON приходят с обратными слэшами и кириллицей
   (`\InstrImg\...\файл.pdf`) — их нормализуем в обычный URL-encoded путь и
   скачиваем. Подпись файла обычно содержит «Изм. № N, <рег. номер>, <год>» —
   по этому скрипт определяет, исходная это версия инструкции или одно из
   последующих изменений.

## Важно: правовой и этический статус

- Это **публичные регуляторные данные**: ГРЛС — официальный государственный
  реестр, карточки препаратов и инструкции по медицинскому применению открыты
  для просмотра любым посетителем сайта без регистрации. Скрипт не обходит
  аутентификацию, не работает с закрытыми разделами и не использует никаких
  уязвимостей — он просто автоматизирует те же запросы, которые делает браузер
  при обычном поиске и просмотре карточки.
- При этом `robots.txt` сайта формально запрещает обход большинства разделов
  (`Disallow: /`, а также отдельно `*.aspx` и `/instrimg/`) — то есть страницы
  поиска, карточки и сами файлы инструкций явно исключены из того, что сайт
  просит роботов не трогать. Это не техническая защита и не нарушение закона
  само по себе, но это явно выраженная позиция владельца сайта, которую стоит
  уважать:
  - используйте скрипт для личных/исследовательских целей и в разумном
    объёме, не для масштабного постоянного переобхода всего реестра;
  - не убирайте и не уменьшайте паузы между запросами (см. «Вежливое
    использование» ниже), не запускайте несколько копий параллельно;
  - если планируете системный/коммерческий сбор данных — открытые выгрузки
    реестра (без обхода капчи и карточек) публикует сам Росздравнадзор на
    главной странице ГРЛС в разделе открытых данных, это предпочтительный
    источник для больших объёмов.

## Установка

```bash
pip install -r requirements.txt
```

Нужен Python 3.10+ (используются `list[dict]`, `X | Y` в аннотациях).

## Использование

```bash
python instructions.py cards.txt --out instructions_output
```

`cards.txt` — текстовый файл, одна запись на строку, строки с `#` игнорируются.
Поддерживаются четыре формата строки:

| Формат | Пример | Что делает скрипт |
|---|---|---|
| **Название** (торговое или МНН) | `Нафтизин`, `Парацетамол` | Ищет на сайте сразу в двух полях — «Торговое наименование» и «МНН» — и объединяет результат. Самый простой способ: не нужно знать номер РУ. Может вернуть **несколько карточек** (разные производители одного МНН, разные формы выпуска) — скрипт скачает инструкции для каждой |
| Номер РУ | `ЛП-007659` | Ищет точно в поле «Номер РУ», берёт карточку с точным совпадением номера. Надёжнее названия, если нужен конкретный препарат конкретного производителя |
| GUID карточки | `437f46de-34cb-4d8f-820b-6fbac6bd88fb` | Сразу подставляет в адрес карточки |
| Полный адрес карточки | `https://grls.rosminzdrav.ru/Grls_View_v2.aspx?routingGuid=...` | Использует как есть |

Строка, начинающаяся на `ЛП-`, `ЛС-` или `ЛСР-`, распознаётся как номер РУ;
всё остальное, что не GUID и не адрес — как название для поиска.

Пример `cards.txt` (10 препаратов неотложной помощи и адреномиметиков, по
номеру РУ) уже включён в репозиторий.

### Результат

Для каждой строки создаётся папка `<out>/<номер РУ>/` с файлами инструкций
(`00_<instruction>_<image>_<имя>.pdf`) и `manifest.json`:

```jsonc
{
  "card_url": "https://grls.rosminzdrav.ru/Grls_View_v2.aspx?routingGuid=...",
  "ru_num": "ЛП-007659",
  "trade_name": "Норэпинефрин Калцекс",
  "note": "...",               // пояснение, если список файлов брался через AddInstrImg, или если что-то не найдено
  "files": [
    {
      "amendment_no": 0,        // 0 — исходная версия, >0 — изменение
      "year": 2021,
      "role": "main",           // main | amendment | unknown
      "file": "00_00_00_....pdf",
      "file_url": "https://grls.rosminzdrav.ru/InstrImg/.../....pdf",
      "bytes": 5821961,
      "sha256": "...",
      "is_pdf": true
    }
  ]
}
```

Полный пример — [`examples/manifest.example.json`](examples/manifest.example.json).

## Проверено на практике

Прогон на 10 препаратах (адреномиметики / средства неотложной помощи) —
Норэпинефрин, Добутамин, Сальбутамол, Фенилэфрин, Нафазолин, Ксилометазолин,
Атропин, Амиодарон, Налоксон, Клонидин — нашёл и скачал 15 PDF-файлов
инструкций (все найдены по номеру РУ автоматически, без ручного поиска в
браузере). У инструкций 2018–2021 годов PDF часто представляет собой скан без
текстового слоя — это особенность того, как сами файлы хранятся в реестре, а
не парсера.

Поиск по названию проверен на запросе `Нафтизин` — найдено 22 карточки
(разные производители и регистрации одного и того же препарата), для каждой
скачана инструкция.

## Вежливое использование

Скрипт не содержит встроенных пауз между запросами — при обработке большого
`cards.txt` добавьте задержку самостоятельно, например:

```python
import time
time.sleep(1)  # между итерациями цикла в main()
```

и не запускайте параллельные процессы на один и тот же список.

## Ограничения

- Работает только с ЛП (лекарственные препараты, `isFS=0`) и ФС (фармацевтические
  субстанции, `isFS=1`) — тип определяется автоматически по ответу поиска.
- Поиск по номеру РУ — точный текстовый поиск сайта; если он возвращает
  несколько карточек, берётся первая с точным совпадением номера РУ, иначе —
  первая из списка.
- Поиск по названию запрашивает у сайта до 200 карточек на один запрос
  (трейд-нейм + МНН вместе); если по запросу найдено ровно 200, скрипт
  печатает предупреждение в stderr — результат может быть обрезан, стоит
  уточнить запрос (например, добавить лекарственную форму или дозировку к
  названию).
- Если карточка найдена, но у препарата нет загруженных файлов инструкции в
  реестре, в `manifest.json` будет пустой список `files` и поясняющий `note`.
