# cards.txt — по одной строке на препарат: адрес карточки ГРЛС, просто GUID,
# номер РУ или просто название. Строки с # игнорируются.
#
# Форматы строки:
#   https://grls.rosminzdrav.ru/Grls_View_v2.aspx?routingGuid=<GUID>   — прямой адрес карточки
#   <GUID>                                                             — просто GUID
#   ЛП-007659                                                          — номер РУ: ищется в поле
#       «Номер РУ» (точный текстовый поиск сайта), даёт одну карточку.
#   Нафтизин  /  Парацетамол                                           — название: ищется сразу
#       и как торговое наименование, и как МНН; может дать СРАЗУ НЕСКОЛЬКО карточек
#       (разные производители одного МНН, разные формы выпуска) — скрипт скачает
#       инструкции для каждой найденной. Если нужен конкретный препарат одного
#       производителя — надёжнее указывать номер РУ.
#
# Поиск (по номеру РУ или по названию) делается через POST /GRLS.aspx — скрипт
# сам находит routingGuid. Капча на странице поиска — не серверная защита
# (см. docstring instructions.py), поэтому ручной поиск в браузере не нужен.
#
